# Änderungsprotokoll

## 1.1.1
- Lesefreigabe für alle `.yaml`-Dateien direkt im Ordner `packages` ergänzt.
- `configuration.yaml` kann jetzt ebenfalls gelesen werden.
- Schutz gegen Pfadmanipulation und symbolische Links verbessert.
- Erkennung häufiger Zugangsdaten-Muster erweitert.
- Automatische Sicherheits- und Funktionstests ergänzt.

## 1.1.0
- Erste Version des separaten, schreibgeschützten MCP-Konfigurationslesers.
- Zugriff ausschließlich auf ausdrücklich freigegebene Package-Dateien.
- Größenbegrenzung und grundlegende Geheimnisprüfung eingeführt.
